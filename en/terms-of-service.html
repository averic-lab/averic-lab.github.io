1. About the Service

Anbu is a daily wellness check application that helps families quietly monitor the well-being of aging parents and loved ones living alone. The Service operates by sending automatic daily wellness signals ("heartbeats") from the monitored person's device to connected family members.

2. Definitions

  1. "Service" means the Anbu mobile application and all related features provided by us.
  2. "Subject" means a user who is registered as the person being checked on, whose device sends daily heartbeat signals.
  3. "Guardian" means a user who is connected to a subject and receives wellness status updates and alert notifications.
  4. "Heartbeat" means the daily wellness signal automatically transmitted from a subject's device.
  5. "Invite Code" means the unique code issued to a subject, used to establish a connection with a guardian.
  6. "Emergency Help Request" means the function by which the Subject directly taps the [🚨] emergency help button within the app to immediately notify all connected Guardians that assistance is needed.

4. Service Description

4.1 Subject Features (Free)

  • Automatic daily heartbeat transmission at a scheduled time
  • Manual wellness report ("I'm okay") button
  • Invite code generation and sharing to connect with guardians
  • Emergency help request feature: tap the [🚨] button to immediately alert all connected guardians (when the user grants location permission, the current location is delivered one time to guardians; if permission is denied, only the alert is delivered without location data)

4.2 Guardian Features (Subscription)

  • Connect with subjects using their invite code
  • Real-time wellness status monitoring
  • Step-by-step alert notifications (Caution → Warning → Urgent)
  • Battery status and device condition alerts
  • Receive subjects' emergency help requests (when location data is included, the location can be viewed on a map)
  • Notification settings and Do Not Disturb configuration
  • Monitor up to 5 subjects with a single subscription
