# FAQ 카피 (언어별)

`build_faq.py`는 이 폴더의 `{lang}.json`을 읽어 그 언어만 생성한다.
언어를 추가하려면 `ko.json`을 복사해 번역하고 파일명을 언어 코드로 바꾸면 된다.
— 스크립트는 고칠 필요가 없다.

## 번역 시 지켜야 할 것

1. **`@`로 시작하는 토큰은 절대 번역하지 않는다.** 앱이 실제로 보여주는 문구로
   빌드 때 치환되며, 번역하면 앱 화면과 어긋난다. (예: `@stability_battery_dialog_title`)
2. **앱 이름**: 한국어만 "안부", 나머지 19개 언어는 "Anbu".
3. 질문은 화면 묘사가 아니라 **증상**으로 쓴다 — 사용자는 앱 화면을 보고 있지 않다.
4. 경고가 뜨는 폰과 증상을 겪는 사람이 다르다. 답변은 "안부를 보내는 분의 폰에서
   확인해 주세요"로 연결한다.
5. 랜딩의 문학적 어조를 쓰지 않는다. 평이하게 2~4문장.
6. 목업 위치를 가리키는 표현("아래 화면에서")을 쓰지 않는다 — 넓은 화면에서는
   오른쪽, 좁은 화면에서는 아래에 온다.
7. `<b>` `<strong>` `<br>` 태그는 그대로 두고 안쪽 텍스트만 옮긴다.
