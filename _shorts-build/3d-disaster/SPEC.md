작업 폴더: `averic-lab/_shorts-build/3d-disaster/` (이 파일이 있는 곳). 공용 도구 사용법은 `/Users/macmini/Project/Anbu/3D_Style_Atlas/_kit/README.md`.

## 렌더 방법
- 장면 하나 = `segs/<장면>/style.js` 하나(`registerStyle({...})`, 참고: `/Users/macmini/Project/Anbu/3D_Style_Atlas/_recipes/<화풍>.ref.js` 와 `_kit/parts/*.js`).
- `node tools/render.mjs <장면> stills 0.5,3,6 16` → `out/<장면>/still_*.png` / `node tools/render.mjs <장면> video 48` → `out/<장면>.mp4` / `node tools/render.mjs <장면> sfx` → `out/<장면>_sfx.wav`
- 긴 장면은 `node tools/render.mjs <장면> video 48 <시작프레임> <끝프레임>` 으로 나눠 동시에 돌릴 수 있다(`out/<장면>_<시작>.mp4`).
- 크기는 `K.run` 이 1080×1920 으로 넘긴다(page.html). 카메라·배치는 **세로 화면**에 맞게 다시 잡는다(참고 코드는 가로용).
- ⚠️ 원본 `3D_Style_Atlas/<화풍>.txt` 는 열지 않는다(너무 크다). `_recipes/<화풍>.md`(STYLE CARD) → `_recipes/<화풍>.ref.js` 순서.
- 정지 화면 확인은 ffmpeg 로 270~360 폭으로 줄여 여러 장을 한 장으로 이어 붙여 본다.

## 공통 규칙
- 자막은 `CAP.draw` (lib/caption.js) — `overlay(ctx, t, W, H) { CAP.draw(ctx, t, W, H, [...]) }`. `*단어*` 호박색 강조, `tag` 는 호박색 알약.
  자막은 화면 위쪽(y 200~520). 장면의 중요한 물체는 그 아래(y 560~1500)에 둔다.
- 안전 영역: 좌우 130px, 위 154px, 아래 384px 안에 글자. 화면 가운데 x=540.
- 한글은 `style.koText` 에 그 장면에서 쓰는 모든 글자를 넣어야 렌더에 빠지지 않는다(page.html 이 미리 불러온다). 일본어 글자도 마찬가지.
- 장면 안 3D 글자는 캔버스에 `"Noto Sans KR"` 로 그린다(Fraunces 등 원본 글꼴엔 한글이 없다).
- 움직임은 전부 시간 t 의 함수(`update(t)`). Math.random 금지, `K.rng(seed)` 사용.
- 실제 앱 아이콘은 `lib/app-icon.png` 만(`ANBU.loadIcon()`). 하트 도형 등 다른 아이콘을 그리지 않는다.
- 특정 회사 로고·제품, 특정 지도 서비스(구글 지도 등) 화면, 특정 OS 화면을 흉내 내지 않는다.
- 효과음은 `sound(k)` 에(style 의 SOUND 도구). 음악은 넣지 않는다(조립할 때 따로 깐다) — sound(k) 안에서 `k.music`·`k.bed` 쓰지 말 것.
- 전쟁·재난 장면에 상처·시체·폭발로 다치는 사람은 그리지 않는다. 사람은 실루엣·작은 종이 인형 수준.

### e1 상세 — 조용히 도착하는 안부 (약 13s)
- 앞 장면(팝업북)이 끝나며 마지막 장을 넘긴 것처럼, 어두운 남색 밤하늘(별·옅은 성운) 위에 **빛나는 알림 카드**가 하나씩 조용히 떠오르며 아래로 쌓인다.
- 카드 모양(참고 스크린샷의 모양): 모서리 둥근 반투명 어두운 유리 카드 + 은은한 흰 빛 테두리(네온처럼 살짝 번짐), 왼쪽 위 실제 앱 아이콘(작게) + `안부 · 지금`, 둘째 줄 **초록색 굵은 제목**, 셋째 줄 흰 본문. 카드 폭은 약 820px(좌우 130 안쪽).
- 카드 4장(문구는 실제 서버 푸시 문구 — 바꾸지 말 것):
  1. `✅ 오늘 안부 확인 완료` / `엄마 · 오늘 3,214보를 걸으셨습니다.`
  2. `✅ 수동 안부 확인` / `아빠 · 보호 대상자가 직접 안부 확인을 보냈습니다.`
  3. `⚠ 주의` (제목 노란색) / `민수 · 오늘 예정된 안부 확인이 아직 없습니다. 직접 확인해 주세요.`
  4. `🚨 긴급 도움 요청` (제목·테두리 붉게 빛남, 카드가 살짝 맥박) / `지수 · 보호 대상자가 직접 도움을 요청했습니다. 즉시 확인해 주세요.`
- 자막: 0.5~4.6s `안부는 하루 한 번, 자동으로` / `*미리 연결한 가족에게* 전해집니다.` · 5.0~8.2s `소식이 없으면,` / `그것도 알려 줍니다.` (카드 3 등장과 맞춤)
- 마지막 약 3s: 긴급 카드만 남고 나머지는 어두워짐 → 손가락(밝은 원형 터치 표시, 손 그림 대신 원이 퍼지는 표시)이 긴급 카드를 누름 → 카드가 펼쳐지며 알림 목록 카드 모양으로 바뀌고 아래에 버튼 `🗺️ 위치 보기` → 그 버튼이 눌림(터치 원). 이 끝에서 화면이 밝은 빛으로 하얗게 날아가며(또는 버튼 안으로 들어가며) e2 로 넘어간다.
- 효과음: 카드마다 작고 부드러운 알림음(1~3은 조용히, 4는 또렷하고 조금 크게), 터치음.

### e2 상세 — 우주에서 내 위치로 (약 9s)
- painted 그림체(인트로와 같은 붓 터치)로 **어두운 우주에 떠 있는 지구**에서 시작 → 동아시아 → 한반도 → 도시(구름층을 뚫고 지나가는 순간이 핵심) → 아파트 동네 → 붉은 위치 표시가 맥박처럼 뛰는 곳까지 계속 줌인(약 6s). 지명·글자는 그리지 않는다.
- 마지막 약 3s: 그 그림 지도가 **휴대폰 화면 속 앱 화면**으로 바뀐다(휴대폰 테두리가 둘러지거나, 화면 가장자리에 앱 UI가 나타남). 앱 화면 구성(실제 앱 「긴급 위치」 페이지): 맨 위 제목 `긴급 위치`, 가운데 지도(붉은 표시), 아래 흰 정보 카드에 `대상자` `지수` / `수집 시각` `오후 9:42` / `정확도` `약 20m` 세 줄과 그 아래 버튼 `외부 지도 앱으로 열기`.
- 자막: 0.4~5.8s `도움이 필요할 땐` / `*위치와 함께* 바로 알릴 수 있습니다.`
- 효과음: 우주의 낮은 울림 → 바람(구름 뚫을 때) → 위치 표시 맥박 소리.
