# 「안부 앱 소개」 3D 판 — 인수인계

원판 `app-intro`(h.html, 2026-10-02, 37.1초, 유튜브 20개 언어 공개)를 **자막은 그대로, 장면은 3D로, 곡은 Electro Dreams 로** 다시 만든 편(2026-11-25 착수).
사용자 지시: 원판처럼 화면이 너무 빨리 넘어가 자막을 놓치지 않게 할 것 / 길이는 상관없음 / 효과음은 알아서.

- 곡: `media/bgm/electro-dreams.mp3`(Arulo, Mixkit house, 120.0 BPM 실측). **1차본(Motivating Mornings)은 "화면과 음악이 따로 논다"로 반려** — 원인은 템포 오차였다:
  원판 h.html 주석의 123.05 BPM 은 틀렸고 실측은 121.0, 게다가 드롭 뒤 약 30초는 킥이 반 박 밀려 있다(원판 공개본도 37초 끝에서 약 0.5초 어긋나 있음).
  ⚠ **곡의 BPM 은 숫자를 믿지 말고 잰다** — `hyperframes beats` 도 반 박을 박으로 잡는다. 실측 도구: `python3 tools/tempo.py <mp3>`(100Hz 온셋 + 주기·위상 탐색 + 16박 창별 위상 검사).
  곡 구조(마디 = 2초): 도입 0–16 / A 16–48 / 브레이크 48–64 / B 64–96 / 마무리 96–112. 장면 1·2 = 도입, 3 = 드롭(16.01초), 6a·6b = 브레이크, 엔딩 = 마무리.
- 자막: 원판 키 그대로(`shorts.json` langs 의 `p_*`, `data/<언어>.js` 의 push_title·steps_tpl·em_btn·app_name·q1·q2·store). `python3 tools/gen_strings.py <언어>` → `lang/<언어>.json`.
- 모든 장면은 마디 단위(1박 = 15프레임) — 장면 경계·자막 쾅·타격이 박 위에 정확히 떨어진다. `lib/kine.js` 의 맥박(마디 첫 박마다 옅은 빛)으로 화면이 박자에 반응한다.
- 읽는 시간: 장면 길이를 원판의 약 2배로. 마지막 줄은 다 뜬 뒤 최소 1.5마디 남고, 앞 줄은 장면 끝까지 남는다(`lib/kine.js`). 컷은 겹치지 않는 바로 잇기 + 장면 첫 순간 번쩍임.

## 렌더 · 조립
```bash
tools/st.sh <장면> 0.5,2,4 [폭]         # 정지 화면 확인(out/<장면>_sheet.png)
tools/render_all.sh                      # 전 장면 영상+효과음(4개 동시). 하나만: SEGS="drop" tools/render_all.sh
python3 tools/assemble.py 0.6 2.0        # → out/app-intro-3d.mp4 (-22 LUFS)
```
`node_modules` 는 `../3d-alone/node_modules` 링크. 커밋 금지: out/·mp4·음원.

## 다국어 때 할 일
- `gen_strings.py` 의 END(엔딩 줄 나누기)·STORE 를 언어별로 채운다. pushBody 숫자 구분자는 `ANBU.num` 규칙과 맞춘다.
- `lib/kine.js` 의 ✕ 꼬리표(suffix)는 폭 맞춤에 포함되지 않는다 — 긴 언어(독일어 p_f1 26자)로 정지 화면 확인.
- price 의 '점심 한 그릇' 그림을 나라별로 바꿀지 결정(원판은 문구만 나라별).
